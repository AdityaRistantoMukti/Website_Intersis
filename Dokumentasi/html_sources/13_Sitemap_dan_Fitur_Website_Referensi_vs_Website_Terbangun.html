Analisis Komparasi Sitemap & Fitur: Website Referensi vs Website Terbangun

Studi Perbandingan Struktur Navigasi, Fitur Unggulan, dan Peningkatan Arsitektur Sistem
Penyusun Aditya Ristanto Mukti Proyek Website Resmi & Profil Industri PT Global Philsonic Technologies
Ringkasan Dokumen Laporan komparatif komprehensif yang membedah arsitektur sitemap dan matriks fitur antara website referensi eksisting (https://www.globalphilsonics.com/isa/) dengan website baru yang dibangun (PT Global Philsonic Technologies). Dokumen ini menguraikan transformasi dari platform monolitik WordPress multi-halaman menjadi Single Page Application (SPA) berbasis React 19, WebGL 3D, Headless CMS, dan sistem bilingual instan.

Pembahasan & Petunjuk Teknis

1. Pendahuluan & Konteks Analisis Perbandingan

Dalam proses rekayasa perangkat lunak website resmi PT Global Philsonic Technologies (Automation-GPT), website resmi eksisting yang beralamat di https://www.globalphilsonics.com/isa/ dijadikan sebagai acuan dasar (benchmark referensi). Analisis perbandingan sitemap dan fitur ini dilakukan untuk memastikan bahwa seluruh informasi bisnis korporat yang telah ada tetap terakomodasi secara utuh, sembari menghadirkan modernisasi arsitektur, peningkatan kecepatan akses, serta fitur interaktif baru berstandar industri Tier-1 internasional.

Pendekatan rekayasa yang diterapkan berfokus pada pembaruan arsitektur dari Multi-Page Traditional CMS menjadi Decoupled Single Page Application (SPA) berkinerja tinggi yang memisahkan lapisan presentasi publik, gerbang API asinkron, dan sistem manajemen konten (CMS) internal.

Karakteristik & Keterbatasan Teknis Website Referensi:

  • Arsitektur Monolitik Tradisional: Website referensi menggunakan CMS WordPress dengan Elementor Builder. Setiap kali pengguna berpindah kategori produk atau menu navigasi, browser melakukan pemuatan ulang halaman penuh (full page reload), yang menyebabkan latensi navigasi dan penggunaan kuota bandwidth lebih tinggi.
  • Fragmentasi Halaman Produk: Setiap lini kategori produk (Amplifier, Subwoofer, DSP, Headunit, Dashcam) dipecah ke dalam URL terpisah. Hal ini menyulitkan pengunjung industri untuk membandingkan spesifikasi teknis lintas kategori secara cepat.
  • Konten Grafis 2D Statis: Seluruh presentasi mesin otomasi industri hanya disajikan dalam bentuk foto gambar diam tanpa visualisasi interaktif atau simulasi 3 dimensi.
  • Ketiadaan Sistem Multi-Bahasa Komponen: Tidak tersedia sistem multi-bahasa terintegrasi pada antarmuka pengguna yang dapat beralih secara instan antara Bahasa Indonesia dan Bahasa Inggris tanpa reload halaman.
  • Formulir Kontak Konvensional: Formulir kontak masih bersifat email umum, belum memiliki klasifikasi estimasi volume pesanan manufaktur (pilot sample vs mass production) maupun sistem validasi skor anti-spam khusus industri.

Fitur Unggulan Nilai Tambah (Value-Added Enhancements) pada Website Baru:

  1. Single Page Unified Product Catalog: Seluruh kategori produk (Headunit, Audio DSP & Amplifier, Dashcam & ADAS, Otomasi & Test Jigs, EMS Box-Build) disatukan dalam satu katalog dinamis dengan filter instan tanpa reload, pencarian SKU cerdas, skema diagram sirkuit, dan modal RFQ langsung.
  2. Simulasi 3D WebGL Robotika Manufaktur (RobotCanvas3D): Visualisasi 3 dimensi model robotika presisi berkecepatan 60 FPS pada halaman /automation yang dapat diputar 360 derajat, mode wireframe, dan tampilan telemetri sumbu (Joint 1 sampai 6).
  3. Sistem Multi-Bahasa Bilingual Instan: Penerapan pustaka i18next pada seluruh halaman yang memungkinkan peralihan bahasa Indonesia dan Inggris secara instan tanpa memicu reload peramban.
  4. Dual Theme Mode (Dark/Light): Pilihan tema gelap berstandar cockpit modern dan tema terang formal dengan persistensi preferensi di localStorage.
  5. Formulir RFQ Khusus Klien Industri Tier-1: Formulir penawaran harga pada halaman /contact dilengkapi pilihan skala produksi (prototipe uji 10-50 unit hingga produksi massal >10.000 unit), pendeteksi alamat IP, negara asal, dan algoritma skor anti-spam otomatis.
  6. Portal Administrasi Mandiri (Headless CMS): Seluruh teks, gambar, angka statistik, dan spesifikasi produk dapat diperbarui secara mandiri oleh staf melalui antarmuka admin yang terproteksi token JWT dan diaudit oleh sistem activity_logs.

4. Matriks Komparasi Fitur & Aspek Rekayasa Sistem

Tabel berikut menyajikan perbandingan terperinci antara website referensi dengan website baru yang dibangun:

Aspek Evaluasi Website Referensi (globalphilsonics.com/isa/) Website Baru yang Dibangun (website_intersis)
Arsitektur Sistem Monolitik WordPress berbasis PHP Server-Side Rendering (SSR). Decoupled 3-Tier: Frontend SPA React 19 + Vite, Backend REST API Node.js Express, dan Database Relasional MySQL 8.
Kecepatan Navigasi Perpindahan menu memicu reload halaman penuh (latensi 1.2s - 2.5s). Client-Side Routing via React Router DOM; navigasi instan (< 100ms) tanpa layar putih (blank screen).
Struktur Katalog Produk Terfragmentasi ke dalam 6 URL halaman terpisah (Headunit, Amplifier, DSP, dll.). Unified Single-Page Catalog: Seluruh kategori produk terintegrasi dalam 1 grid berfilter instan dan pencarian SKU real-time.
Spesifikasi Teknis Teks statis sederhana pada deskripsi halaman Elementor. Tersimpan dalam kolom JSON terstruktur (specs dan full_specs) yang dapat ditampilkan via Modal Interaktif dan Skema Diagram.
Visualisasi Otomasi Gambar foto 2 dimensi statis. Interactive WebGL 3D Robot Canvas (Three.js) dengan rotasi 360°, pencahayaan directional, wireframe mode, dan HUD telemetri sumbu.
Multi-Bahasa (Bilingual) Hanya satu bahasa default, atau mengandalkan Google Translate widget eksternal. Integrasi native i18next: Seluruh komponen dan konten CMS mendukung peralihan instan Bahasa Indonesia dan Bahasa Inggris.
Tema Tampilan (Theme) Hanya satu mode tampilan standar (Light theme statis). Dual Theme: Mode Gelap (Dark Mode industrial) dan Mode Terang (Light Mode) yang tersinkronisasi di localStorage.
Formulir Penawaran (RFQ) Formulir kontak umum pengirim pesan email standar. Formulir Request for Quotation (RFQ) profesional dengan pemilihan skala volume produksi, skor anti-spam, dan integrasi WhatsApp sales.
Pengelolaan Konten (CMS) Mengandalkan WP-Admin bawaan yang rentan celah keamanan plugin. Custom Admin Portal mandiri berbasis JWT, dilindungi role RBAC (Admin, HRD, Staff), dan dilengkapi audit trail activity_logs.
Keamanan Data & DB Skema tabel WordPress default (wp_posts, wp_postmeta). Database relasional 3NF terindeks (15 tabel fisik), password dienkripsi bcrypt 10 salt rounds, dan kueri terparameterisasi aman.

6. Kesimpulan Analisis Komparatif

Berdasarkan analisis komparasi sitemap dan matriks fitur yang telah dipaparkan, dapat disimpulkan bahwa:

  1. Seluruh konten, kategori produk (Headunit, Audio, Dashcam), identitas korporat, dan informasi kontak dari website referensi globalphilsonics.com/isa/ telah berhasil diserap dan dimigrasikan ke dalam website baru tanpa ada data yang hilang.
  2. Website baru menghadirkan lompatan teknologi (technological leap) yang signifikan: navigasi instan berbasis SPA React 19, katalog terpadu dengan modal spesifikasi teknis mendalam, visualisasi robotika 3D WebGL, sistem bilingual instan, dual-theme, formulir penawaran RFQ anti-spam, serta sistem administrasi headless CMS mandiri yang aman dan ter-audit.
  3. Transformasi ini menempatkan portal digital PT Global Philsonic Technologies pada standar industri otomotif internasional yang siap bersaing dalam menarik mitra bisnis Tier-1 global.
