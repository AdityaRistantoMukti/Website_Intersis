1.1. Identifikasi Mock-up & Translasi Wireframe ke Komponen Reaktif

Lokasi Berkas: frontend/src/pages/public/HomePage.jsx & ProductsPage.jsx

Identifikasi mock-up dilakukan untuk menerjemahkan spesifikasi antarmuka industri elektronika otomotif dan rekayasa otomasi (Automation-GPT) ke dalam susunan komponen visual reaktif yang modular:

  • Hero Section Dinamis: Dilengkapi tombol aksi langsung (direct redirection) berukuran besar menuju katalog produk otomasi (/products) dan formulir penawaran RFQ (/contact).
  • Bento Grid Architecture: Diterapkan pada AboutPage.jsx dan HomePage.jsx untuk menampilkan data sejarah pabrik Batam Free Trade Zone (FTZ), sertifikasi IATF 16949 / ISO 9001, dan nilai inti korporat.
  • Katalog Produk Berfilter: Grid kartu produk responsif yang menampilkan kode SKU model, badge kategori (Headunit, Audio DSP, Dashcam, EMS), spesifikasi teknis ringkas, dan modal unduh skema diagram.

1.2. Penyusunan Hirarki Dialog UI & Form Input Multi-Tab Transaksional

Lokasi Berkas: frontend/src/pages/admin/modules/ProductsModule.jsx & GalleryModule.jsx

Hirarki dialog antarmuka memisahkan interaksi tampilan cepat, formulir berstruktur, dan konfirmasi aksi kritis:

  • Tingkat 1 (Modal Penampil Ringkas): Dialog pop-up spesifikasi produk lengkap (ProductSpecsModal.jsx) dan Lightbox foto galeri industri tanpa merubah state navigasi halaman.
  • Tingkat 2 (Modal Form Input Multi-Tab): Dialog pengelolaan produk pada admin panel yang membagi formulir ke dalam 4 tab sekuensial (Identitas Model, Judul & Deskripsi Bilingual, Specs Singkat, dan JSON Spesifikasi Lengkap).
  • Tingkat 3 (Dialog Konfirmasi Transaksional): Feedback aksi transaksional berbasis sistem toast notifikasi real-time dan dialog validasi schema sebelum pengiriman data via Axios.

const handleSaveProduct = async (e) => {
  e.preventDefault();
  if (!form.model_code.trim()) {
    addToast('Kode Model Produk wajib diisi.', 'error');
    setModalTab('identity');
    return;
  }

  const formData = new FormData();
  formData.append('model_code', form.model_code);
  formData.append('category', form.category);
  formData.append('badge', form.badge || '');
  formData.append('title_id', form.title_id);
  formData.append('title_en', form.title_en);
  formData.append('specs', JSON.stringify(cleanSpecs));
  formData.append('full_specs', JSON.stringify(form.full_specs || {}));

  setSubmitting(true);
  try {
    if (isEdit) {
      await api.put(`/admin/products/${product.id}`, formData);
      addToast(`Produk '${form.model_code}' berhasil diperbarui!`, 'success');
    } else {
      await api.post('/admin/products', formData);
      addToast(`Produk baru '${form.model_code}' berhasil ditambahkan!`, 'success');
    }
    onSaved();
  } catch (err) {
    addToast(extractErrorMessage(err), 'error');
  } finally {
    setSubmitting(false);
  }
};

1.3. Penerapan Tampilan Interaktif (WebGL 3D Robot Canvas & Multi-Bahasa)

Lokasi Berkas: frontend/src/components/automation/RobotCanvas3D.jsx & src/lib/i18n.js

Fitur interaktif dieksekusi secara teroptimasi pada thread grafis browser:

  1. Interactive 3D Robot Canvas: Menggunakan Three.js pada RobotCanvas3D.jsx untuk merender model robotika manufaktur berkecepatan 60 FPS dengan kontrol rotasi, mode wireframe, pencahayaan directional spotlight, dan visualisasi telemetri sumbu (joint 1-6).
  2. Sistem Multi-Bahasa Bilingual: Integrasi i18next yang memungkinkan peralihan bahasa Indonesia dan Inggris secara instan tanpa memicu reload halaman web.
  3. Persistensi Tema Gelap/Terang: Pengendalian class dark pada elemen dokumen HTML dengan sinkronisasi ke localStorage peramban klien.
