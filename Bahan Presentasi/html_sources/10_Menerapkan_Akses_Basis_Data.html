10.2. Konfigurasi Connection Pool & Adaptabilitas Cloud Database

Kaitkan ke Codebase: backend/src/config/database.js

Konfigurasi pool mendeteksi keberadaan URL koneksi cloud otomatis, memberikan fallback ke parameter localhost saat pengembangan offline:

backend/src/config/database.js 
const mysql = require('mysql2/promise');
require('dotenv').config();

// Konfigurasi Dinamis: Mendukung Railway Cloud URL & Local XAMPP
const poolConfig = process.env.MYSQL_URL || process.env.DATABASE_URL
  ? {
      uri: process.env.MYSQL_URL || process.env.DATABASE_URL,
      waitForConnections: true,
      connectionLimit: 10,
      queueLimit: 0,
      timezone: '+07:00',
      charset: 'utf8mb4'
    }
  : {
      host: process.env.DB_HOST || 'localhost',
      port: parseInt(process.env.DB_PORT || '3306'),
      user: process.env.DB_USER || 'root',
      password: process.env.DB_PASSWORD || '',
      database: process.env.DB_NAME || 'isa_career_hrd',
      waitForConnections: true,
      connectionLimit: 10,
      queueLimit: 0,
      timezone: '+07:00',
      charset: 'utf8mb4'
    };

const pool = mysql.createPool(poolConfig);

// Validasi Konektivitas Saat Inisialisasi Server
pool.getConnection()
  .then(conn => {
    console.log('[DB] MySQL Connected — Pool Ready');
    conn.release();
  })
  .catch(err => console.error('[DB] Connection Error:', err.message));

module.exports = pool;

V. Matriks Tanya Jawab & Panduan Pembelaan Sidang (Q&A Defense)

Prediksi pertanyaan evaluasi dari Penguji / Asesor / Pembimbing Industri beserta jawaban teknis yang siap dipertahankan:

Q1: Mengapa tidak menghubungkan React langsung ke database menggunakan driver MySQL browser?
Jawaban Pembelaan Presenter: Database MySQL menggunakan protokol TCP berbasis socket mentah yang tidak didukung langsung oleh browser tanpa perantara, dan yang terpenting: menyematkan kredensial database pada kode JavaScript client-side akan memungkinkan siapa saja membuka DevTools browser untuk melihat password database dan memanipulasi seluruh tabel sesuka hati.
Q2: Apa fungsi dari parameter queueLimit: 0 pada konfigurasi pool mysql2?
Jawaban Pembelaan Presenter: queueLimit: 0 menandakan bahwa jumlah antrean permintaan koneksi tidak memiliki batas buatan. Jika ke-10 koneksi sedang sibuk, request baru akan mengantre secara tertib (FIFO) hingga ada koneksi yang selesai dan di-release, alih-alih langsung menolak request dengan pesan error 'Queue Limit Reached'.
