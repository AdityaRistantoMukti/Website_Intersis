Hirarki dialog antarmuka memisahkan secara tegas level interaksi antara pengguna umum dan pengguna administratif internal:

Level Dialog Komponen / Trigger Tujuan & Manajemen State
Level 1: Modal View selectedJob di CareerPage / Gallery Lightbox Menampilkan rincian persyaratan kualifikasi atau foto resolusi tinggi tanpa memindahkan URL rute aplikasi.
Level 2: Form Drawer / Dialog Modal Input Lowongan & Produk Baru di Admin Mengisolasi form pengisian data multipart/form-data dengan validasi real-time sebelum submit ke REST API.
Level 3: Critical Confirm SweetAlert2 Confirmation Dialog Pencegahan accidental delete dengan dialog konfirmasi modal bertingkat dan handling promise async/await.

// Penanganan Dialog Interaktif Konfirmasi Hapus Data via SweetAlert2
const handleDeleteJob = async (id, title) => {
  const result = await Swal.fire({
    title: 'Hapus Lowongan?',
    text: `Apakah Anda yakin ingin menghapus "${title}"? Data tidak dapat dikembalikan.`,
    icon: 'warning',
    showCancelButton: true,
    confirmButtonColor: '#ef4444',
    cancelButtonColor: '#64748b',
    confirmButtonText: 'Ya, Hapus!',
    cancelButtonText: 'Batal'
  });

  if (result.isConfirmed) {
    await apiClient.delete(`/api/admin/jobs/${id}`);
    Swal.fire('Terhapus!', 'Lowongan pekerjaan telah dihapus.', 'success');
    loadJobs();
  }
};

1.3. Penerapan Tampilan Interaktif, Animasi 3D, dan Multi-Bahasa

Kaitkan ke Codebase: frontend/src/components/home/HeroGlobe.jsx & src/i18n.js

Interaktivitas website diperkuat melalui tiga pilar komputasi browser modern:

  1. Interactive WebGL Canvas (Cobe & Three.js): Menghitung matriks proyeksi lingkaran bumi bola secara 60 FPS menggunakan WebGL shader ringan, memungkinkan pengguna memutar globe secara halus mengikuti interaksi drag mouse.
  2. Bilingual Localization Engine (i18next): Mendeteksi preferensi browser dan memungkinkan pengguna beralih antara Bahasa Indonesia dan Bahasa Inggris secara instan tanpa flickering halaman.
  3. Theme Persistence Engine: Mengatur penambahan class dark pada tag <html> dan menyinkronkannya ke local storage browser untuk kenyamanan mata pengguna di lingkungan redup.
frontend/src/components/automation/AutomationGlobe.jsx 
// Inisialisasi WebGL 3D Globe dengan Library Cobe
import createGlobe from 'cobe';
useEffect(() => {
  let phi = 0;
  const globe = createGlobe(canvasRef.current, {
    devicePixelRatio: 2,
    width: 600 * 2,
    height: 600 * 2,
    phi: 0,
    theta: 0.25,
    dark: isDark ? 1 : 0,
    diffuse: 1.2,
    mapSamples: 16000,
    mapBrightness: 6,
    baseColor: [0.1, 0.15, 0.25],
    markerColor: [0.1, 0.8, 1],
    markers: [{ location: [1.1301, 104.0529], size: 0.1 }], // Lokasi Batam, Indonesia
    onRender: (state) => {
      state.phi = phi;
      phi += 0.003; // Otomasi rotasi halus
    }
  });
  return () => globe.destroy();
}, [isDark]);

V. Matriks Tanya Jawab & Panduan Pembelaan Sidang (Q&A Defense)

Prediksi pertanyaan evaluasi dari Penguji / Asesor / Pembimbing Industri beserta jawaban teknis yang siap dipertahankan:

Q1: Mengapa Anda memilih kombinasi Tailwind CSS v4 dan CSS manual pada halaman About/Home, tidak pure utility?
Jawaban Pembelaan Presenter: Tailwind v4 kami gunakan untuk utilitas layouting cepat dan konsistensi spacing token, sedangkan CSS manual (seperti AboutPage.css) digunakan untuk kalkulasi keyframes 3D transform, tracing-beam pseudo-elements, dan glassmorphism backdrop-filter kompleks yang memerlukan presisi performa GPU rendering.
Q2: Bagaimana cara Anda menjamin performa rendering tetap ringan saat memuat animasi 3D WebGL di perangkat mobile?
Jawaban Pembelaan Presenter: Kami mengatur devicePixelRatio secara adaptif, mematikan loop kalkulasi saat canvas keluar dari viewport (menggunakan IntersectionObserver), serta menurunkan mapSamples dari 16.000 menjadi 8.000 pada resolusi layar ponsel di bawah 768px.
