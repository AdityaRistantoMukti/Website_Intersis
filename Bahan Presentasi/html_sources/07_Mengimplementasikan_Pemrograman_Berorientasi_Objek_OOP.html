7.1 & 7.4. Penerapan Class ES6 & Pewarisan Objek (Inheritance)

Kaitkan ke Codebase: backend/src/utils/ApiError.js

Pewarisan kelas diterapkan pada sistem manajemen exception untuk menciptakan hierarki error yang mudah diidentifikasi oleh middleware:

backend/src/utils/ApiError.js 
// Penerapan Class & Inheritance: Mewarisi Kelas Induk 'Error'
class ApiError extends Error {
  constructor(statusCode, message, isOperational = true, stack = '') {
    super(message); // Memanggil konstruktor kelas induk
    this.statusCode = statusCode;
    this.isOperational = isOperational;
    this.status = `${statusCode}`.startsWith('4') ? 'fail' : 'error';

    if (stack) {
      this.stack = stack;
    } else {
      Error.captureStackTrace(this, this.constructor);
    }
  }
}

module.exports = ApiError;

7.2 & 7.3. Objek DTO & Enkapsulasi Keamanan Kredensial Pengguna

Kaitkan ke Codebase: backend/src/controllers/admin/authController.js

Enkapsulasi data sensitif diterapkan menggunakan teknik hashing kriptografis satu arah, menyembunyikan representasi asli sandi pengguna:

backend/src/controllers/admin/authController.js 
// Enkapsulasi: Menyembunyikan Detail Password dengan Bcrypt Hashing
exports.login = async (req, res, next) => {
  const { username, password } = req.body;
  
  const [users] = await db.query('SELECT * FROM users WHERE username = ? AND status = "active"', [username]);
  if (users.length === 0) {
    return res.status(401).json({ success: false, message: 'Kredensial tidak valid.' });
  }

  const user = users[0];
  // Verifikasi hash tanpa pernah mendekripsi password ke bentuk asli
  const isMatch = await bcrypt.compare(password, user.password);
  if (!isMatch) {
    return res.status(401).json({ success: false, message: 'Kredensial tidak valid.' });
  }

  // Objek Response Bersih: Menghilangkan properti password dari output DTO
  const userResponseDTO = { id: user.id, name: user.name, username: user.username, role: user.role };
  const token = jwt.sign(userResponseDTO, process.env.JWT_SECRET, { expiresIn: '8h' });

  res.json({ success: true, token, user: userResponseDTO });
};

7.5 & 7.6. Polimorfisme Komponen UI & Standarisasi Kontrak Interface

Kaitkan ke Codebase: frontend/src/components/ui/Button.jsx

Komponen UI polimorfis menyesuaikan perwujudan visual dan fungsi interaksinya sesuai kontrak interface properti yang diterima:

frontend/src/components/ui/Button.jsx 
// Polimorfisme Komponen: Menyesuaikan Gaya Berdasarkan Prop Variant
export default function Button({ children, variant = 'primary', className = '', ...props }) {
  const baseStyles = 'px-5 py-2.5 rounded-xl font-medium transition-all duration-200 flex items-center justify-center gap-2';
  
  const variantStyles = {
    primary: 'bg-gradient-to-r from-blue-600 to-cyan-500 text-white shadow-md hover:shadow-cyan-500/25',
    secondary: 'bg-slate-800 text-slate-200 hover:bg-slate-700 border border-slate-700',
    danger: 'bg-red-600 text-white hover:bg-red-700 shadow-md hover:shadow-red-500/25',
    outline: 'border border-blue-500/40 text-blue-400 hover:bg-blue-500/10'
  };

  return (
    <button className={`${baseStyles} ${variantStyles[variant]} ${className}`} {...props}>
      {children}
    </button>
  );
}

V. Matriks Tanya Jawab & Panduan Pembelaan Sidang (Q&A Defense)

Prediksi pertanyaan evaluasi dari Penguji / Asesor / Pembimbing Industri beserta jawaban teknis yang siap dipertahankan:

Q1: Mengapa Anda memilih membuat custom class ApiError daripada sekadar melempar objek biasa throw { status: 404, msg: 'Error' }?
Jawaban Pembelaan Presenter: Dengan meng-extends kelas Error bawaan JavaScript, objek ApiError tetap mempertahankan captureStackTrace() yang mencatat nomor baris dan berkas lokasi terjadinya kesalahan. Ini sangat krusial saat debugging di log server, sedangkan objek literal biasa tidak memiliki informasi stack trace.
Q2: Bagaimana Anda menerapkan prinsip Encapsulation pada layer database?
Jawaban Pembelaan Presenter: Kami mengisolasi seluruh interaksi SQL di dalam controller dan repository backend. Komponen frontend tidak dapat melihat struktur query SQL mentah maupun kredensial koneksi database, melainkan hanya berinteraksi melalui endpoint REST API yang telah tervalidasi.
