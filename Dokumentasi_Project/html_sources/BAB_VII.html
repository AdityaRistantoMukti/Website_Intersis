7.1 Fungsi Kunci Backend Controllers

Nama Fungsi / Method Berkas Lokasi Tugas Logika & Alur Eksekusi
login() controllers/admin/authController.js Mencari username di database, membandingkan password via bcrypt.compare(), menerbitkan token JWT bertandatangan aman, dan mencatat log login.
getJobVacancies() controllers/public/publicJobController.js Menjalankan query SQL dengan filter dinamis (kategori, tipe kerja, kata kunci), menghitung total paginasi, dan menyesuaikan bahasa respon berdasarkan header klien.
createJob() / updateJob() controllers/admin/adminJobVacancyController.js Menyimpan atau memperbarui data lowongan. Menerapkan transaksi data, validasi tautan form pendaftaran, dan mencatat log mutasi ke tabel activity_logs.
submitRfq() controllers/telemetryController.js Menerima formulir penawaran harga manufaktur, memeriksa batasan rate limiter, memvalidasi email, dan menyiapkan teks pesan ringkasan transaksi.
translateContent() controllers/admin/translateController.js Mesin utilitas yang memproses teks Bahasa Indonesia menjadi draf terjemahan Bahasa Inggris untuk mempercepat kerja staf HRD saat menginput lowongan.
getProducts() controllers/public/publicProductController.js Mengambil data 12 produk dari tabel products, mem-parsing kolom spesifikasi berformat JSON string menjadi objek JavaScript, dan mengurutkannya.

7.2 Middlewares & Utilitas Keamanan

Middleware / Helper Berkas Lokasi Mekanisme Kerja & Fungsi Keamanan
verifyToken middlewares/authMiddleware.js Mengekstrak token Bearer dari header Authorization, mendekripsi via jwt.verify(), dan menyematkan payload user ke dalam req.user.
restrictTo(...roles) middlewares/authMiddleware.js Mengecek apakah role user pada req.user.role terdaftar dalam parameter yang diizinkan. Mengembalikan 403 Forbidden jika tidak berwenang.
errorHandler middlewares/errorHandler.js Menangkap seluruh error tak tertangani, mencatat rincian ke konsol internal, dan menyajikan pesan aman kepada klien.
deleteFileIfLocal() utils/fileCleanup.js Menghapus berkas fisik lama di folder uploads/ saat admin mengunggah berkas pengganti baru untuk mencegah pemborosan kapasitas harddisk server.
upload.single() middlewares/uploadMiddleware.js Konfigurasi Multer untuk menangani berkas gambar dengan filter mime-type ketat (JPEG, PNG, WEBP) dan batas ukuran maksimal 5 Megabytes.

7.3 Custom Hooks & State Management Frontend

  • useLanguage(): Mengembalikan nilai bahasa aktif saat ini (lang), fungsi pengubah bahasa (setLang), serta fungsi bantu terjemahan t(key) yang mengambil pasangan frasa dari berkas kamus locales/.
  • useAuth(): Menyediakan data sesi akun admin (nama, email, role, token), status pengecekan otentikasi (isAuthenticated), serta fungsi login(credentials) dan logout().
  • formatDate(dateString, lang): Mengubah format tanggal ISO dari database MySQL menjadi format bacaan formal manusia (contoh: "19 Oktober 2026" atau "October 19, 2026").
