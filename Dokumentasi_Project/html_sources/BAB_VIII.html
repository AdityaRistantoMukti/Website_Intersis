8.1 Katalog Berkas Kunci Direktori Backend

Path & Nama Berkas Deskripsi Peran & Tanggung Jawab Teknis
backend/src/server.js Titik masuk utama aplikasi Node.js. Menginisialisasi Express, mengaktifkan middleware keamanan (Helmet, CORS, Body Parser), menghubungkan rute publik dan admin, serta menangani error handler terpusat.
backend/src/config/db.js Modul pool koneksi MySQL menggunakan mysql2/promise. Mengelola antrean koneksi, uji konektivitas awal, dan penanganan pemutusan jaringan database.
backend/src/routes/publicRoutes.js Mendefinisikan 15 rute endpoint publik (profil perusahaan, produk, otomasi, lowongan kerja, form RFQ, telemetri) yang dapat diakses oleh publik tanpa otentikasi.
backend/src/routes/adminRoutes.js Mendefinisikan seluruh rute terproteksi dashboard admin, menerapkan filter token JWT, pembatasan hak akses role, penanganan upload berkas, dan validator input.
backend/src/middlewares/authMiddleware.js Berisi implementasi fungsi verifyToken dan restrictTo untuk pengamanan gerbang API administratif.
backend/src/middlewares/rateLimiter.js Konfigurasi ambang batas permintaan IP untuk menangkal brute-force login dan spam formulir RFQ.
backend/src/validators/contentValidators.js Aturan validasi field untuk modul profil perusahaan, kontak, nilai inti, produk, galeri, benefit, dan FAQ.
backend/src/validators/jobVacancyValidator.js Aturan validasi ketat untuk pembuatan lowongan pekerjaan (kategori, format tipe kerja, deskripsi kualifikasi).
backend/src/utils/fileCleanup.js Utilitas penghapusan berkas fisik lokal di server ketika ada pergantian aset gambar oleh admin.
backend/.env Berkas konfigurasi variabel lingkungan yang memuat port server, nama database, kredensial pengguna MySQL, dan kunci rahasia enkripsi JWT.
