4.1 Pemilihan Database Engine & Karakteristik Teknis

Saya memilih MySQL (InnoDB Engine) sebagai sistem manajemen basis data relasional utama. Pilihan ini didasarkan pada kepatuhan penuh terhadap prinsip ACID (Atomicity, Consistency, Isolation, Durability), dukungan native Foreign Key Constraints untuk menjaga integritas data, serta efisiensi indexing B-Tree yang sangat handal untuk pembacaan katalog produk dan lowongan kerja. Seluruh tabel menggunakan konfigurasi character set utf8mb4 dan collation utf8mb4_unicode_ci guna mendukung penyimpanan karakter multi-bahasa, simbol teknik otomotif, dan tanda baca internasional.

4.2 Skema Tabel & Kamus Data (Data Dictionary)

Berikut adalah tabel-tabel utama yang saya rancang dan operasikan pada database isa_career_hrd:

A. Tabel users (Akun Manajemen Internal)

Nama Kolom Tipe Data Atribut Keterangan & Nilai Standar
id INT PK, Auto Increment Identifikator unik akun pengguna internal.
name VARCHAR(100) NOT NULL Nama lengkap pengguna / staf administrasi.
username VARCHAR(50) NOT NULL, UNIQUE Username untuk otentikasi login sistem.
email VARCHAR(100) NOT NULL, UNIQUE Alamat email resmi untuk notifikasi dan audit.
password VARCHAR(255) NOT NULL Hash kata sandi terenkripsi menggunakan algoritma bcrypt (salt rounds: 10).
role ENUM NOT NULL Tingkat akses: 'administrator', 'hrd', 'staff'.
status ENUM DEFAULT 'active' Status akun: 'active' atau 'inactive'.
created_at / updated_at TIMESTAMP CURRENT_TIMESTAMP Waktu pembuatan akun dan pembaruan terakhir.

B. Tabel job_vacancies (Daftar Lowongan Kerja)

Nama Kolom Tipe Data Atribut Keterangan & Relasi
id INT PK, Auto Increment Identifikator unik lowongan.
category_id INT FK, NOT NULL Relasi foreign key ke job_categories(id) (ON DELETE RESTRICT).
title / title_en VARCHAR(150) NOT NULL / NULL Judul posisi pekerjaan versi Bahasa Indonesia dan Inggris.
location VARCHAR(100) DEFAULT 'Batam' Penempatan kerja (contoh: Batam Free Trade Zone).
employment_type ENUM NOT NULL Tipe kerja: 'FullTime', 'PartTime', 'Internship', 'Contract', 'OJT'.
description / description_en TEXT NULL Uraian umum posisi dan ikhtisar divisi kerja.
responsibilities / responsibilities_en TEXT NOT NULL Daftar rincian tugas dan tanggung jawab harian karyawan.
requirements / requirements_en TEXT NOT NULL Syarat kualifikasi teknis, latar pendidikan, dan pengalaman.
form_url VARCHAR(500) NULL Tautan formulir pendaftaran daring (Google Form / Portal Seleksi).
status ENUM DEFAULT 'draft' Status siklus lowongan: 'draft', 'published', 'closed'.
created_by INT FK, NULL Relasi foreign key ke users(id) untuk audit pembuat data.

C. Tabel products (Katalog Elektronik & Robotik Otomasi)

Nama Kolom Tipe Data Atribut Keterangan & Format Data
id INT PK, Auto Increment Identifikator unik produk.
model_code VARCHAR(100) NOT NULL Nomor model manufaktur (contoh: GPT-HU9800 PRO, GPT-ROBOT-WELD).
category ENUM NOT NULL Kategori lini: 'headunit', 'audio', 'dashcam', 'automation', 'ems'.
title_id / title_en TEXT NOT NULL Nama komersial produk dalam bahasa Indonesia dan Inggris.
short_desc_id / short_desc_en TEXT NULL Ringkasan fitur unggulan produk untuk kartu ringkasan.
specs LONGTEXT NULL JSON array berisi 4 spesifikasi ringkas [{"label": "...", "value": "..."}].
full_specs LONGTEXT NULL JSON object spesifikasi teknik lengkap (tegangan, suhu kerja, DAC, sertifikasi).
diagram_type VARCHAR(50) DEFAULT 'infotainment' Penentu diagram arsitektur visual pada antarmuka frontend.
status / sort_order TINYINT(1) / INT DEFAULT 1 / 0 Status aktif dan urutan prioritas penampilan produk.

4.3 Entitas Pendukung & Singleton Pattern

Untuk kebutuhan master data lainnya, saya merancang beberapa tabel pendukung:

  • company_profile & contact_recruitment: Menerapkan Singleton Pattern (hanya menyimpan 1 baris rekaman tunggal ID 1). Endpoint hanya melayani pembacaan (GET) dan pengkinian (PUT), mencegah duplikasi data profil.
  • core_values: Menyimpan 4 pilar filosofi kerja dengan dukungan bilingual dan penanda ikon visual.
  • gallery: Menyimpan dokumentasi visual kegiatan operasional pabrik dengan referensi user pengunggah.
  • benefits & programs: Mengelola informasi fasilitas tunjangan kerja dan program magang vokasi di Batam.
  • activity_logs: Menyimpan rekam jejak setiap aksi mutasi data (CREATE, UPDATE, DELETE, LOGIN) untuk kebutuhan audit internal kepatuhan ISO 9001.
