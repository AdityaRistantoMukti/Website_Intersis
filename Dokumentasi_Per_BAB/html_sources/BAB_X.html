10.1 Ringkasan Perbandingan Transformasi Sistem

Proyek rekayasa ulang ini telah berhasil mentransformasi website lama menjadi platform digital modern kelas industri:

Aspek Perbandingan Kondisi Website Lama (WordPress CMS) Kondisi Website Baru (Fullstack Modern)
Arsitektur Sistem Monolitik WordPress 6.9.9 + Elementor 4.1.4 lambat. Decoupled React.js SPA + Express REST API + MySQL.
Kecepatan Rendering Waktu muat > 4 detik; DOM tree membengkak oleh plugin. Waktu muat < 1.5 detik; bundling Vite ringan & instan.
Katalog Robotik Teks statis di sub-halaman tanpa interaktivitas. Showcase 3 Pilar Robotik lengkap dengan kanvas visual 3D.
Katalog Produk Elektronik Gambar statis seadanya tanpa spesifikasi detail. 12 Produk unggulan terinci (spesifikasi teknik & sertifikasi).
Modul Karir / HRD Tidak ada sama sekali. Portal karir publik + Dasbor HRD terproteksi JWT.
Saluran Konversi (Leads) Kontak statis umum tanpa sistem penawaran harga. Formulir RFQ otomatis & integrasi WhatsApp telemetri.
Dukungan Bahasa Bahasa Inggris seadanya tanpa opsi Bahasa Indonesia. Sistem bilingual penuh (ID / EN) dari DB hingga UI.

10.2 Hasil Pengujian Fungsionalitas & Kompatibilitas

Saya telah melakukan serangkaian pengujian terukur sebelum merilis sistem ke tahap akhir:

  • Pengujian Responsivitas Multi-Perangkat: Antarmuka diuji pada resolusi desktop lebar (1920x1080), laptop (1366x768), tablet iPad (768x1024), serta layar smartphone (iPhone & Android 375px s.d. 414px). Seluruh elemen tata letak flexbox dan grid beradaptasi secara harmonis.
  • Pengujian Validasi & Keamanan API: Pengujian endpoint melalui Postman Runner menunjukkan 100% permintaan berhasil sesuai status code yang diharapkan (200, 201, 400, 401, 403, 404, 429).
  • Pengujian Alur Rekrutmen: Simulasi pembukaan lowongan oleh HRD di dasbor admin langsung terbit secara real-time di halaman karir publik, dan tombol "Apply Now" berhasil mengarahkan pelamar ke formulir pendaftaran yang tepat.

10.3 Kesimpulan & Rekomendasi Pemeliharaan Sistem

Secara keseluruhan, sistem website baru PT. Global Philsonic Technologies (GPT) di bawah naungan PT. Intersis Sejahtera Abadi (ISA) telah berhasil diselesaikan dengan mutu rekayasa perangkat lunak yang tinggi, andal, dan siap mendukung pertumbuhan bisnis perusahaan di kancah industri internasional.

Untuk pemeliharaan jangka panjang, saya menyarankan beberapa langkah operasional berikut:

  1. Pencadangan Basis Data Otomatis (Database Backup): Menjadwalkan cron job harian pada server MySQL untuk mengekspor berkas dump database ke penyimpanan cloud terisolasi.
  2. Rotasi Kunci Rahasia JWT: Melakukan pembaruan nilai JWT_SECRET di file .env secara berkala (misalnya setiap 6 bulan sekali) guna meminimalkan risiko eksploitasi sesi lama.
  3. Pemantauan Kapasitas Penyimpanan: Memantau penggunaan disk space pada folder uploads/ dan mempertimbangkan migrasi ke penyimpanan obyek cloud (seperti AWS S3 atau Cloudinary) jika volume dokumentasi foto galeri terus meningkat.
