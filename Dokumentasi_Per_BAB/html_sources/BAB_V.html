5.1 Pemilihan Teknologi & Filosofi Antarmuka

Pada sisi antarmuka, saya mengimplementasikan Single Page Application (SPA) berbasis React 18 / 19 yang dikompilasi menggunakan Vite. Pendekatan ini memberikan pengalaman penjelajahan yang sangat cepat tanpa reload halaman (zero full-page refreshes). Berbeda dengan template WordPress lama yang sarat dependensi CSS berat, saya merancang sistem styling kustom berbasis Vanilla CSS murni dengan CSS Custom Properties (Design Tokens). Pendekatan ini menjamin fleksibilitas penuh, performa rendering 60 FPS, ukuran bundle akhir yang sangat kecil, serta tampilan visual modern yang elegan.

5.2 Routing Dinamis & Code Splitting (Lazy Loading)

5.3 Manajemen State Global & Arsitektur Provider

Untuk mengelola data yang diakses lintas komponen, saya membangun 3 Context Provider utama:

  • LanguageContext: Mengelola status bahasa aktif ('id' atau 'en'). Menyediakan fungsi toggleLanguage() dan kamus terjemahan untuk seluruh elemen UI statis. Pilihan bahasa pengguna disimpan secara persisten di localStorage sehingga tidak hilang saat tab ditutup.
  • AdminAuthContext: Mengelola sesi login administrator, penyimpanan token JWT, parsing payload profil pengguna, serta fungsi otomatisasi pembersihan sesi (auto-logout) saat token dinyatakan kedaluwarsa oleh backend.
  • BrandingContext: Mengambil konfigurasi visual terkini dari backend (logo perusahaan, nama instansi, tautan favicon dinamis, dan kontak darurat) dan mendistribusikannya ke Navbar serta Footer secara real-time.

5.4 Komponen Kunci Khusus (Inovasi Fitur)

  1. RobotCanvas3D (Halaman Automation): Komponen interaktif yang merender model representasi lengan robot multi-sumbu secara dinamis menggunakan HTML5 Canvas, memberikan kesan teknologi tinggi (Industry 4.0) kepada calon klien industri.
  2. Interactive RFQ Modal: Kotak dialog penawaran harga terintegrasi yang menghitung estimasi kebutuhan perakitan dan langsung mengirimkan draf inquiry ke server dan WhatsApp tim sales engineering.
  3. WhatsApp Floating Action Button: Tombol melayang cerdas yang menyertakan pelacakan halaman asal pengunjung (telemetri) untuk memudahkan tim sales mengetahui produk apa yang sedang dilihat calon pembeli saat menghubungi WhatsApp.
